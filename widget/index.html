IWP Chatbot Widget

This is the embeddable chatbot widget for Indian Wedding Planners.

Usage

Add this script to your website:

<script src="https://iwp-chatbot-widget.vercel.app/iwp-chatbot.iife.js"></script>
<script>
  const widget = new IWPChatbot({
    apiUrl: 'https://your-backend-url.onrender.com/api/v1'
  });
  widget.init();
</script>

Direct bundle: iwp-chatbot.iife.js
